# Семейный бюджет

Сайт для ведения общего бюджета семьи (Анна и Кирилл). Валюта — сум.

- **Фронтенд:** один файл `index.html` (GitHub Pages)
- **База и вход:** Supabase (проект `anechka-path`, таблицы `fb_*`, доступ только участникам семьи через RLS)
- Публичный ключ в коде — publishable, он безопасен: без входа данные не видны.

## Таблицы
- `fb_households` — семья и настройки (план по умолчанию)
- `fb_members` — участники (Анна, Кирилл)
- `fb_months` — месяцы и плановые суммы по 6 категориям
- `fb_entries` — приходы, расходы и переводы между категориями

## Резервная копия
«Ещё → Скачать резервную копию (JSON)» / «Восстановить из файла (JSON)».
Восстановление понимает и файлы старой версии приложения (localStorage), повторы пропускаются.
